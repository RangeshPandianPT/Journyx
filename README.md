# Journyx Transport Booking Platform

A modern, professional transport booking platform built with React 19, Tailwind CSS, TanStack Router, and Radix UI.

## Features
- **Dynamic Search**: Seamless location and date search functionality.
- **Seat Selection**: Interactive, stateful bus seat layout.
- **Mock Booking Engine**: A full booking flow from search to confirmation.
- **My Bookings Dashboard**: Manage and track upcoming and past bookings.

## Getting Started

First, run the development server:

```bash
npm run dev
# or
yarn dev
# or
bun run dev
```

Open [http://localhost:8080](http://localhost:8080) with your browser to see the result.
